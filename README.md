# 🎯 TOEIC 訓練計畫

免費線上 TOEIC 多益訓練工具，依目標分數自動配置每日練習，無需註冊、純前端運作。

🔗 **線上使用**：[https://q896321-bit.github.io/toeic-trainer/](https://q896321-bit.github.io/toeic-trainer/)

---

## 功能總覽

### 📋 智慧訓練規劃
- 選擇目標分數（450 / 550 / 650 / 750）
- 選擇訓練天數（30 / 60 / 90 天）
- 輸入目前聽力 / 閱讀成績，系統自動分析弱項並調配訓練比重

### 📖 每日訓練模組
| 模組 | 內容 |
|------|------|
| 單字練習 | Emoji 圖像記憶卡片 + 🔊 發音 + 🐢 慢速播放 + 例句朗讀 |
| 拼寫測驗 | 看中文拼英文，支援語音提示 |
| 文法重點 | 分級文法教學 + 即時答題回饋 |
| 聽力測驗 | TTS 語音播放 → 作答 → 查看原文 |
| 閱讀練習 | 商業情境文章 + 理解題 + 文章朗讀 |

### 📚 Part 1-7 分類練習
針對 TOEIC 七大題型獨立訓練：
- Part 1-4：聽力（照片描述、應答問題、簡短對話、簡短獨白）
- Part 5-7：閱讀（句子填空、段落填空、閱讀理解）

### 🏢 商業情境主題
六大 TOEIC 常考場景分類練習：
- 辦公室 / 會議、旅遊 / 飯店、購物 / 餐廳
- 人資 / 招聘、財務 / 預算、行銷 / 廣告

### 📕 錯題本
- 自動記錄所有答錯題目
- 依類型篩選（聽力 / 閱讀 / 文法 / 單字）
- 顯示你的答案 vs 正確答案 + 解析

### ⚡ 閱讀速度訓練
- 可選速度：100 / 150 / 200 / 250 WPM
- 逐字高亮追蹤訓練眼球速度
- 🔊 正確發音播放（正常速 + 慢速）
- 完成後可重複聽 + 換新文章

### 📊 每日學習報告
完成訓練後自動顯示：
- 正確率、花費時間
- 各類別（聽力 / 閱讀 / 文法）分項統計
- 弱項分析建議

### 🏆 成就系統
12 個獎章里程碑：
- 連續天數（3 / 7 / 14 / 30 天）
- 正確率（80% / 100%）
- 速讀成績（200 / 250 WPM）
- 錯題複習、進度達標等

### 🔧 其他功能
- 🌙 **深色模式** — 一鍵切換，自動記住偏好
- 💻 **手機 / 電腦模式切換** — 手機上也能用桌面版排版
- 📤 **分享功能** — 手機原生分享 / 桌面複製連結
- ⏱️ **計時器** — 模擬考試時間壓力
- 💾 **進度暫存** — localStorage 保存，關掉瀏覽器再開仍在

## 技術架構

```
toeic-trainer/
├── index.html      # 主頁面（SPA 多頁面切換）
├── style.css       # 樣式（RWD + 深色模式）
├── app.js          # 核心邏輯（TTS、計時、成就、錯題追蹤）
├── data.js         # 題庫資料（單字、文法、聽力、閱讀、Part練習）
└── manifest.json   # PWA 設定
```

- **純前端**：HTML + CSS + JavaScript，無需後端
- **語音合成**：Web Speech API（瀏覽器內建 TTS）
- **資料儲存**：localStorage（進度、設定、錯題紀錄）
- **部署**：GitHub Pages 靜態託管
- **PWA**：可加到手機主畫面如 App 使用

```bash

open index.html

npx serve .
```
